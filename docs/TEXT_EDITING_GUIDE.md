# Editing the game's text

All paths below are relative to the project root, `C:\Users\abid\Documents\its-probably-fine`. In Godot, prefix these paths with `res://`. The game currently uses hardcoded GDScript strings and a few scene properties, not a localization database. No dialogue framework migration is required to edit copy.

Use [TEXT_INVENTORY.md](TEXT_INVENTORY.md) to find exact text, templates, source files and functions. Its [technical appendix](TEXT_INVENTORY_INTERNALS.md) retains the remaining literals so short keys and generated names can also be traced. Some inventory candidates are speaker names or code keys rather than prose: read their use before editing.

## Formatting rules

- Save source as UTF-8. Keep curly quotes, dashes and accents intact; do not let Windows ANSI encoding replace them.
- Edit inside existing quoted strings. Escape embedded double quotes as `\"`; use `\n` for intentional line breaks. Do not insert a physical newline into a normal single-line GDScript string.
- If a string is formatted using `%`, preserve the number/order/type of placeholders: `%s` text, `%d` integer, `%.0f`/`%.1f` numeric. Use `%%` for a literal percent **in formatted strings only**. Ordinary strings use `%` once. The inventory context shows the formatting argument expression when it immediately follows the literal.
- Keep speaker names exactly `Judy` and `TipTop`; expression identifiers must match portrait asset keys. Empty Judy text plus a response key is intentional dynamic dialogue, not missing copy.
- Comic dialogue uses `_dialogue_pages()`, `_dialogue_line_breaks()` and `_dialogue_fits()` with current font metrics. Keep sentences complete; the pager retains remainders. Do not replace these methods with a character cutoff.
- BBCode appears in `RichTextLabel` checklist rows. Keep `[color]`, `[/color]`, `[s]`, `[/s]` balanced. Plain `Label` text does not interpret BBCode.
- Button captions sometimes double as routing keys. Search the exact caption with `rg -n --fixed-strings 'caption' scripts scenes data` before renaming it. Do not bulk-replace a word that is also a routine/event/property ID.
- Some notifications drive contextual explanations using the phrases `not enough time`, `full repair needs` or `Mosquito`. Preserve these or update the matching checks deliberately. Do not change those checks for a text-only pass without inspecting their behavior.
- Time, cost, reward and threshold numbers are gameplay data in `scripts/game_state.gd`. Rewrite surrounding prose, not the values. Rules difficulty values are injected automatically; literal descriptions of thresholds must remain synchronized if balance changes later.

## Inventory maintenance and manual review

Run `python tools/build_text_inventory.py` to regenerate the two inventory documents after copy changes. This is source-documentation generation, not a Godot launch or gameplay test. IDs are snapshot locators; source path, function and line are the useful editing coordinates.

After editing, manually review the affected menu/page at the actual window size, long comic lines for both portraits, narrow sidebar wrapping, tutorial bubbles and save-error text. Check E/Enter and Back/Next behavior, then return to movement. No automated layout or runtime verification has been performed for this pass.
